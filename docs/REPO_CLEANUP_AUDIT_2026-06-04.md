# Repo Cleanup Audit - 2026-06-04

This audit records the medium-scope redundancy cleanup for the `super` checkout. The cleanup keeps active runtime and product surfaces intact while removing retired root-level frontend files and low-risk generated artifacts.

## Deleted

Tracked retired root frontend app:

- `src/`
- `index.html`
- `vite.config.ts`
- `tsconfig.json`
- `tsconfig.node.json`
- `tailwind.config.js`
- `postcss.config.js`

Ignored reproducible artifacts targeted for cleanup:

- Python `__pycache__/`
- `.pytest_cache/`
- `backend/.pytest_cache/`
- `.playwright-cli/`
- `.chrome-headless-profile/`
- `.codex-security-scans/`
- `.logs/`
- `output/playwright/`

If active local processes hold files under `.logs/`, Windows may leave those locked files in place. The directory remains ignored and can be cleaned after the owning processes stop.

## Retained

- `frontend/src/`: active frontend product surface.
- `backend/app/`: active backend API, core services, models, and module runtime.
- `scripts/`: canonical local validation, smoke, startup, and packaging helpers.
- Root `package.json` and `package-lock.json`: Windows-friendly launcher and dependency lock entrypoints.
- Root `eslint.config.js`: shared ESLint flat config used by frontend lint from the `frontend/` working directory.
- `tianyuan_quant_v10_2_multi_agent_files/`: still referenced by backend runtime prompt loading and Docker packaging.
- `frontend/dist/`: retained unless immediately regenerated by `npm.cmd run build`; route smoke expects a built preview.
- Runtime storage and dependency directories.

## Deferred

The following are intentionally marked but not removed automatically:

- `.uv-cache/`
- `.uv-runtime-cache/`
- `.tmp/`
- `.venv/`
- `backend/.venv/`
- `node_modules/`
- `frontend/node_modules/`
- `backend/app/storage/`
- `storage/`

Reasons: these paths can contain active local dependencies, locked temp databases, uv launch/build state, or runtime data. Deleting them can break startup, slow validation, or remove local state.

Reproducible Python `__pycache__/` bytecode under ignored dependency/cache directories may be removed, but the dependency/cache directories themselves are retained.

## Guard Rails

- `backend/tests/test_repo_hygiene.py` now guards that the retired root frontend paths stay removed.
- The same hygiene test verifies root npm launchers continue delegating frontend commands to `frontend/`.
- Developer-facing docs now describe the root frontend as removed rather than retained for reference.
